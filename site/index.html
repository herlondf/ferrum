Git, fast.

Ferrum is a native Git client written in Rust. A clear history graph, staging down to single lines, interactive rebase by drag and drop and a three-way conflict resolver, with no account and no telemetry.

Features

Built for daily work on real repositories

Ferrum reads with libgit2 for speed and writes with your own git, so hooks, credential helpers, SSH and LFS behave exactly as in the terminal.

History that stays readable

Colored lanes, collapsible merges, first-parent and topological order, reflog, and branch filters saved per repository.

Stage lines, not just files

Pick hunks or single lines in the diff, discard what you don't want, amend, sign off and push after commit.

Interactive rebase by drag and drop

Reorder, squash, fix up, reword and drop commits in a planner, with a preview of conflicts before running.

Three-way conflict resolver

Choose per conflict, edit the result, resolve images, LFS files and submodules, and undo a resolution.

Pull requests and issues

Accounts for GitHub, GitLab, Bitbucket, Azure DevOps and Gitea: list, check out and create pull requests, browse issues, see GitHub notifications.

Nothing hidden

The Activity window shows every git command Ferrum ran, with its output. Long operations can be cancelled.

Undo

Ctrl+Z reverts commits, checkouts, branch and tag changes, merges and rebases.

Keyboard first

A command palette, Open Quickly for repositories, and shortcuts you can change for everything.

Native and light

A Rust binary drawn on the GPU, no Electron. Dark, light and high-contrast themes, Inter and JetBrains Mono.

macOS

If a download link does not work yet, the first release has not been published: see all releases or build from source with cargo build --release. Every release lists SHA-256 checksums in SHA256SUMS. Flathub, winget, Scoop and Homebrew: coming soon.
