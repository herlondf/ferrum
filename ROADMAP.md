# Roadmap

## Phase 1 — everyday basics
- [x] Open repositories in tabs
- [x] Sidebar: local branches, remote branches, tags
- [ ] Sidebar: stashes, remotes
- [x] Commit history list (all branches)
- [x] Commit graph (colored branch lanes)
- [x] Branch and tag labels in the history
- [x] Commit details (hash, author, date, parents)
- [ ] Commit details: changed files and diff
- [ ] Changes view: unstaged/staged, stage files, hunks and lines
- [ ] Commit, amend
- [ ] Fetch, pull, push with progress
- [ ] Create, checkout, rename, delete branches
- [ ] Merge, stash

## Phase 2 — power features
- [ ] Visual interactive rebase (reorder, squash, edit)
- [ ] Three-way merge conflict resolver
- [ ] Cherry-pick and revert from context menu
- [ ] History search (message, author, hash, content)
- [ ] Blame and file history
- [ ] Keyboard shortcuts and command palette
- [ ] Light and dark themes

## Phase 3 — integrations
- [ ] GitHub / GitLab login, view and create pull requests
- [ ] Undo recent actions
- [ ] Git LFS, submodules, worktrees
- [ ] User profiles (name, email, SSH/GPG key)
- [ ] Image diff
