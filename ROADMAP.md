# Roadmap

## Phase 1 — everyday basics
- [x] Open repositories in tabs
- [x] Sidebar: local branches, remote branches, tags, stashes, remotes
- [x] Commit history list with colored branch graph and labels
- [x] Commit details: changed files and diff
- [x] Changes view: unstaged/staged, stage files, hunks and lines
- [x] Commit, amend
- [x] Fetch, pull, push with progress
- [x] Create, checkout, rename, delete branches
- [x] Merge, stash

## Phase 2 — power features
- [x] Visual interactive rebase (reorder, squash, edit)
- [x] Three-way merge conflict resolver
- [x] Cherry-pick and revert from context menu
- [x] History search (message, author, hash, content)
- [x] Blame and file history
- [x] Keyboard shortcuts and command palette
- [x] Light and dark themes

## Phase 3 — integrations
- [x] GitHub / GitLab login, view and create pull requests
- [x] Undo recent actions
- [x] Git LFS, submodules, worktrees
- [x] User profiles (name, email, SSH/GPG key)
- [x] Image diff

## Ideas for later
- Watch the working copy for changes instead of refreshing on focus
- Word-level highlighting in diffs
- Side-by-side diff mode
- Automatic periodic fetch
- External merge/diff tool integration
- Installers (MSI, DMG, Flatpak)
